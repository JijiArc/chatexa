Encrypted file vault

Files are encrypted in your browser before upload, so the host stores only random-looking bytes. Send the link and the password to the other person by different routes.

📁 Click to select files, or drag & drop here

How it works: pick files, choose a password, upload. Each file becomes one encrypted .enc file on the host. The host sees its size and when it was uploaded, and your IP address, but not the name or content. Anyone with a link can download the encrypted file, so a weak password can be guessed offline.
